# คู่มือเริ่มต้นใช้งานฉบับเร่งด่วน (AI Quick Start)

> สำหรับเจ้าของร้านและพนักงาน — งานประจำวันทำตรงไหน กดเมนูอะไร แบบสั้น กระชับ จบในหน้าเดียว
>
> ทุกขั้นตอนในคู่มือนี้อ้างอิงจากเมนูจริงในระบบ POS Today เท่านั้น ถ้าระบบยังไม่มีฟีเจอร์ไหน จะระบุไว้ตรง ๆ ว่า "ขณะนี้ระบบยังไม่มีข้อมูลส่วนนี้"

---

## 🌅 วันนี้เปิดร้าน ทำอะไรบ้าง

**เมนู: แดชบอร์ด (`/dashboard`)**

1. เข้าสู่ระบบ → เลือกร้านของคุณ
2. เปิด **แดชบอร์ด** ดูสรุปยอดขายและสต็อกของวันนี้
3. ดูการ์ด KPI ทั้ง 7 ใบ: ยอดขายรวม, กำไรขั้นต้น, จำนวนออเดอร์, มูลค่าสต็อก, ลูกหนี้ (AR), ค่าใช้จ่าย, กำไรสุทธิ
4. ใช้ตัวกรองวันที่ (วันนี้ / 7 วัน / 30 วัน / กำหนดเอง) แล้วดูกราฟแนวโน้มยอดขาย
5. เลื่อนลงไปดูส่วน **"สินค้าที่ต้องจับตา"** เพื่อวางแผนสั่งของ

> 💡 สีม่วง = ยอดขายเงินสดปกติ • สีส้ม = ยอดขายเชื่อ/ลูกหนี้
> 💡 ถาม Copilot ได้ว่า "ภาพรวมเป็นไง" → ได้คะแนนสุขภาพร้าน 0–100 + สรุปวันนี้

---

## 🛒 วันนี้อยากขาย

**เมนู: หน้าขาย (`/sales`)**

1. กดปุ่ม **หน้าขาย** เพื่อเปิดหน้าจอแคชเชียร์
2. กดที่สินค้า หรือ **สแกนบาร์โค้ด** เพื่อใส่ลงตะกร้า (ค้นหาด้วยชื่อ / SKU / บาร์โค้ดก็ได้)
3. ปรับจำนวนในตะกร้า → ถ้าจะลดราคา กดที่สินค้า/ไอคอน ✏️ ใส่ส่วนลด (บาท หรือ %) หรือกด **"ส่วนลดท้ายบิล"**
4. กด **"ชำระเงิน"** → เลือกวิธี (เงินสด / บัตร / โอน / ผสม) → ใส่ยอดรับ → ยืนยัน
5. ระบบ **พิมพ์ใบเสร็จอัตโนมัติ**

**ทางเลือกอื่นตอนกด "ชำระเงิน":**
- **พักบิล** — กดเมนู (⋮) บนตะกร้า → "พักบิล" ตั้งชื่อโต๊ะ/ลูกค้า → เรียกคืนจากไอคอน 📋 ด้านบน
- **ใบเสนอราคา** — กด "ใบเสนอราคา" ตั้งวันหมดอายุ → บันทึกไว้ในเมนูเอกสาร
- **เปิดบิลเชื่อ** — ดูหัวข้อ "เช็กลูกหนี้" ด้านล่าง

> 💡 ปุ่ม "รับพอดี" ตั้งยอดรับให้อัตโนมัติ • สลับ VAT 7% ได้ด้วยสวิตช์

---

## 📦 อยากรับสินค้า

**เมนู: จัดซื้อ / รับสินค้า → รับสินค้าเข้า (`/warehouse/receive`)**

1. เข้าเมนู **จัดซื้อ** หรือ **คลังสินค้า** → **รับสินค้าเข้า**
2. กด **"สร้างใบรับใหม่"**
3. เลือก **ผู้จัดจำหน่าย** และผูกกับ **ใบสั่งซื้อ (PO)** ถ้ามี
4. กรอกรายการที่รับ, จำนวน, และต้นทุน (แนบใบส่งของผู้ขายได้ ถ้ามี)
5. กด **"ยืนยันการรับ"** → สต็อกเพิ่มขึ้นทันที

> 💡 ระบบมีขั้นตอนแบบทีละสเต็ป: เลือกสินค้า → ตรวจจำนวน → สรุปใบรับ
> 💡 ตรวจสต็อกหลังรับได้ที่ **คลังสินค้า → สต็อกสินค้า** (`/inventory`)

---

## 📝 อยากสั่งของ

**เมนู: จัดซื้อ → การสั่งซื้อ (`/purchases`)**

1. เข้าเมนู **จัดซื้อ → การสั่งซื้อ (PO)**
2. กด **"+ สร้างใบสั่งซื้อใหม่"**
3. เลือก **ผู้จัดจำหน่าย** → เพิ่มรายการสินค้า พร้อมจำนวนและราคา
4. ตรวจยอดรวม → กด **"ส่ง PO"** (สถานะ "รออนุมัติ" → เปลี่ยนเป็น "อนุมัติ" เมื่อผู้ขายยืนยัน)

**จัดการผู้จัดจำหน่าย:** เมนู **จัดซื้อ → ผู้จัดจำหน่าย** (`/purchases/suppliers`)
- กด "+ เพิ่มผู้จัดจำหน่าย" → กรอกชื่อบริษัท, เลขภาษี 13 หลัก, ข้อมูลติดต่อ → ตั้งเครดิต (เช่น Net 30) → บันทึก

> 💡 ถาม Copilot ว่า "ควรสั่งอะไรบ้าง" → ได้รายการสินค้าใกล้หมดที่ควรสั่ง (top 3) พร้อมเหตุผล
> 💡 ถาม Copilot เรื่องซัพพลายเออร์ได้: ยอดสั่งซื้อรวม, ความเสี่ยงพึ่งซัพรายเดียว, PO ที่ค้างอยู่

## 💰 เช็กกำไร

**เมนู: รายงาน & การเงิน (`/reports/summary`) — เฉพาะเจ้าของ/ผู้จัดการ**

1. **รายงานสรุป** (`/reports/summary`) — เลือกช่วงวันที่ → ดูการ์ด KPI 8 ใบ (รายได้, ต้นทุน, กำไรขั้นต้น, ส่วนลดรวม, ค่าใช้จ่าย, กำไรสุทธิ, % margin, ลูกหนี้) + ตารางสรุป P&L รายเดือน
2. **กำไรขาดทุน (P&L)** (`/finance/pnl`) — ตั้งช่วงเวลา → ดูสูตร: รายได้ − ต้นทุนขาย = กำไรขั้นต้น − ค่าใช้จ่าย = กำไรสุทธิ
3. **บันทึกรายจ่าย** (`/finance/expenses`) — กด "+ เพิ่มรายจ่าย" → เลือกหมวด (ค่าเช่า/สาธารณูปโภค/เงินเดือน/อื่น ๆ) → ใส่ยอดและวันที่ → กระทบ P&L ทันที

> 💡 ตัวเลขสีแดงในคอลัมน์กำไร = ขาดทุนในเดือนนั้น
> 💡 ถาม Copilot ว่า "กำไรเป็นไง" → ได้งบ P&L (7 วัน + วันนี้): กำไรขั้นต้น/สุทธิ/ดำเนินงาน พร้อมป้ายสถานะ
> ⚠️ ขณะนี้ระบบยังไม่มีข้อมูลแนวโน้มย้อนหลังเกิน 7 วัน (เช่น 30 วัน / เทียบปีต่อปี) ในฝั่ง Copilot — ดูช่วงยาวได้ที่หน้ารายงานแทน

## 🧾 เช็กลูกหนี้

**เมนู: ขายเชื่อ / ยืม (`/credit-sales`)**

**เปิดบิลเชื่อ:** ที่หน้าขาย กด "ชำระเงิน" → แท็บ **"เปิดบิลเชื่อ"** → ค้นหาและเลือกลูกค้า → ตั้งวันครบกำหนด → ปรับส่วนลด/VAT → กด "เปิดบิลเชื่อ"

**รับชำระหนี้:**
1. เข้าเมนู **ขายเชื่อ / ยืม**
2. หาบิลของลูกค้า → กด **"รับชำระ"**
3. ใส่ยอดและวิธีชำระ → ยืนยัน → สถานะเปลี่ยนเป็น "ชำระแล้ว"

**คืนสินค้ายืม:** ในบิลแบบ "ยืม" → กด "คืนสินค้า" → เลือกรายการ/จำนวน → ยืนยัน → สินค้ากลับเข้าสต็อก

> 💡 ต้องเพิ่มลูกค้าเป็นสมาชิกก่อน (เมนู **ลูกค้า** `/customers`)
> 💡 ดูบิลค้างชำระทั้งหมดได้ที่ **เอกสาร → บิลค้างชำระ** (`/documents/pending`)
> 💡 ถาม Copilot ว่า "ลูกหนี้เป็นไง" → ได้ยอดค้างรวม, แบ่งตามอายุหนี้ (30/60/90/90+ วัน), ลูกหนี้เกินกำหนด (top 3)

---

## ⚠️ เช็กของหมด

**เมนู: คลังสินค้า → สต็อกสินค้า (`/inventory`)**

1. เข้าเมนู **คลังสินค้า → สต็อกสินค้า** → ดูตารางสินค้าทั้งหมดพร้อมสต็อกคงเหลือ
2. กรองได้: ต่ำกว่าเกณฑ์ / หมดสต็อก / ตามหมวดหมู่
3. กดที่สินค้าเพื่อดูประวัติการเคลื่อนไหวสต็อก
4. ดูสรุปได้ที่ **แดชบอร์ด** ส่วน "สินค้าที่ต้องจับตา" — กด "สั่งซื้อ" เพื่อสร้าง PO ให้สินค้านั้นได้เลย

**ตรวจนับสต็อก:** เมนู **คลังสินค้า → ตรวจนับสินค้า** (`/inventory/counts`)
- กด "สร้างรอบนับใหม่" → ตั้งขอบเขต → ใส่จำนวนจริง/สแกนบาร์โค้ด → ดูส่วนต่าง → กด "ยืนยัน" เพื่อปรับสต็อก

> 💡 ถาม Copilot ว่า "ของหมดยัง / ใกล้หมดไหม" → ได้จำนวนสินค้าหมดสต็อก, ใกล้หมด, รายการที่ต้องรีบสั่ง (top 3), ทุนจม
> 💡 ดูมูลค่าสต็อกและสินค้าค้างได้ที่ **รายงาน → มูลค่าสต็อก & สินค้าค้าง** (`/reports/inventory-value`)
> ⚠️ ขณะนี้ระบบยังไม่มีข้อมูลอันดับสินค้าขายดีรายตัวใน Copilot (มีแต่ความเร็วการขายจากรายการที่ต้องรีบสั่ง) — ดูอันดับขายดีจริงได้ที่หน้ารายงานสรุป

## 🔒 ปิดร้าน

**เมนู: แดชบอร์ด (`/dashboard`) + บันทึกกิจกรรม (`/settings/activity-logs`)**

1. เปิด **แดชบอร์ด** เลือกวันที่ = วันนี้ → ตรวจยอดขาย, จำนวนออเดอร์, กำไรของวัน
2. เคลียร์บิลที่ค้าง: ดู **เอกสาร → บิลค้างชำระ** และ **ขายเชื่อ / ยืม** ว่ามีอะไรต้องตามเก็บ
3. เช็กของใกล้หมดเพื่อวางแผนสั่งพรุ่งนี้ (ส่วน "สินค้าที่ต้องจับตา")
4. ตรวจการแก้ไขของวัน: **ตั้งค่า → บันทึกกิจกรรม** — ดูว่าใครแก้อะไร เมื่อไร (กรองตามหมวด/ความสำคัญ/คำค้น)

> 💡 ถาม Copilot ในแท็บ "ถามระบบ" ได้ เช่น "ใครแก้ราคาสินค้า X" → ระบบค้นบันทึกกิจกรรมแล้วตอบ ก่อน→หลัง
> ⚠️ ขณะนี้ระบบยังไม่มีข้อมูลขั้นตอนปิดยอดเงินสด/ปิดกะ/กระทบเงินในลิ้นชัก (cash reconciliation / shift closing) เป็นฟีเจอร์เฉพาะ — ใช้แดชบอร์ดและบันทึกกิจกรรมสรุปแทน

## ℹ️ เคล็ดลับใช้ Copilot (ผู้ช่วยอัจฉริยะ)

Copilot ตอบจากข้อมูลจริงของร้าน (ไม่ใช่การคุยทั่วไป) ถามเป็นหัวข้อสั้น ๆ ได้เลย:

| อยากรู้ | พิมพ์ถามแบบนี้ |
|---------|----------------|
| ภาพรวมร้าน | "ภาพรวมเป็นไง" / "สรุปร้าน" |
| ยอดขาย | "ยอดขายเท่าไร" / "ขายเป็นไง" |
| กำไร | "กำไรเป็นไง" / "ขาดทุนไหม" |
| สต็อก/ของหมด | "ของหมดยัง" / "ใกล้หมดไหม" |
| ลูกหนี้ | "ลูกหนี้เป็นไง" / "ใครค้างชำระ" |
| สั่งของ/ซัพ | "ควรสั่งอะไร" / "ซัพพลายเออร์เป็นไง" |
| ควรทำอะไรก่อน | "วันนี้ควรทำอะไร" / "อะไรสำคัญ" |
| ใครแก้ข้อมูล | "ใครแก้ราคา X" / "ใครเปลี่ยนอะไร" |
| วิธีใช้งาน | "วิธี..." / "ทำไง..." (ดึงจากศูนย์ช่วยเหลือ) |

> ⚠️ ขณะนี้ระบบยังไม่มีข้อมูลการสั่งให้ Copilot ทำงานแทน (เช่น "สร้าง PO ให้" / "ปรับสต็อกให้") — ยังต้องทำเองในเมนู
> 💡 ต้องการคู่มือเต็ม: เมนู **ช่วยเหลือ** (`/help`)
